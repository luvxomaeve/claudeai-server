# 🔮 Магический Шар & Таро / Magic Ball & Tarot

HTML5-игрушка: «волшебный шар» с ответами на вопросы (да/нет) + полная
колода Таро (78 карт) с раскладами и трактовками. Двуязычный интерфейс
(RU/EN), работает офлайн, готова к публикации на **Яндекс Играх** и
в **Google Play**.

## Что внутри

```
magic-ball/
├── index.html        # точка входа
├── css/style.css     # стили, анимации (шар, переворот карт)
├── manifest.json     # PWA-манифест (для установки и TWA)
├── sw.js             # service worker (офлайн-кэш)
├── icons/            # иконки 192/512, maskable, apple-touch, favicon,
│                     #   feature-graphic 1024×500 для Google Play
├── js/
│   ├── i18n.js       # строки интерфейса + ответы шара (RU/EN)
│   ├── tarot.js      # колода 78 карт + 4 расклада (трактовки RU/EN)
│   └── app.js        # логика, Yandex Games SDK, детекция тряски, звук
└── README.md
```

Внешних зависимостей, картинок и сборки **нет** — чистый HTML/CSS/JS.
Карты нарисованы эмодзи + CSS, звук синтезируется через Web Audio.

## Возможности

- **Шар:** вопрос → тряска телефона *или* тап по шару → ответ
  (20 классических ответов в каждом языке, лёгкий позитивный перекос).
- **Таро:** 4 расклада — Карта дня, Три карты (прошлое/настоящее/будущее),
  Ситуация (ситуация/препятствие/совет), Кельтский крест (10 карт).
  Карты могут выпадать перевёрнутыми (своя трактовка).
- Переключатель языка RU/EN и звука, настройки сохраняются.
- **Yandex Games SDK** подключён: инициализация, сохранение настроек в
  профиль игрока, полноэкранная и rewarded-реклама. Без SDK (локально или
  на другой площадке) всё работает в режиме заглушек.

## Локальный запуск

```bash
cd magic-ball
python3 -m http.server 8080
# открыть http://localhost:8080
```

> Тряска телефона работает только на реальном устройстве по HTTPS
> (на iOS требуется тап для запроса доступа к акселерометру). На десктопе
> используйте тап/кнопку «Встряхнуть».

## Реклама (Yandex Games)

Частота показа задаётся в `js/app.js` → `maybeShowAd()` (сейчас каждое
3-е действие). Доступны методы `YA.showFullscreenAd()` и
`YA.showRewardedAd(cb)`. Перед релизом проверьте требования Яндекса к
частоте межстраничной рекламы.

## Публикация на Яндекс Играх

1. Зайти в [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console).
2. Создать черновик игры, заполнить название/описание/иконки/скриншоты.
3. Загрузить ZIP с содержимым папки `magic-ball/` (важно: `index.html`
   должен быть в корне архива). SDK уже подключён в `index.html`.
4. Настроить рекламные блоки и категорию, отправить на модерацию.

## Публикация в Google Play

Вариант A — **TWA (Trusted Web Activity)** через [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap):
сначала разместите игру на любом HTTPS-хостинге, затем оберните URL в TWA
и соберите `.aab` для Google Play. Нужно добавить `manifest.json` и иконки.

Вариант B — **Capacitor**: обернуть статику в нативный контейнер.

```bash
npm i -g @bubblewrap/cli       # вариант A
bubblewrap init --manifest https://ВАШ_ДОМЕН/manifest.json
bubblewrap build
```

> `manifest.json`, service worker, иконки (192/512, maskable, apple-touch,
> favicon) и feature graphic 1024×500 (`icons/feature-graphic-1024x500.png`)
> уже в комплекте. Останется добавить только политику конфиденциальности
> (требование Google Play).

## Как расширять

- **Ответы шара:** `js/i18n.js` → `BALL_ANSWERS`.
- **Трактовки карт:** `js/tarot.js` → `TAROT_DECK`.
- **Новый расклад:** добавить ключ в `TAROT_SPREADS` (список позиций) —
  UI и сетка карт подхватят автоматически.
- **Тема/цвета:** CSS-переменные в начале `css/style.css`.
