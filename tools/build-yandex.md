# Сборка для Яндекс Игр

Релиз = те же `src/` и `style.css`, плюс:
- библиотеки локально в `lib/` (three 0.169, three-vrm 3.1, нужные addons) вместо CDN;
- `<script src="/sdk.js">` (SDK Яндекс Игр), `window.WAIFU_RELEASE = true`
  (нет кнопки «Макс», камера не ниже колен);
- модели — облегчённые `.glb` (`tools/optimize-vrm.py`) в `models/` — **не коммитить**
  (лицензия моделей: только для автора).

Корень архива — `index.html`, имена без пробелов и кириллицы, < 100 МБ.
