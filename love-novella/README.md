# Созвездие наших чувств ✨🌙

Романтическая визуальная новелла на чистом HTML5/CSS/JS — без зависимостей и сборки.
История Романа (фотограф, за него играешь) и Анны: от первого сообщения в приложении —
к кафе, летнему парку и звёздам, под которыми всё решается.

**Арка:** знакомство в приложении → первая встреча в кафе → парк под звёздами и первое
совместное фото → испытание на доверие → ночь близости → предложение под звёздами → финал.

## Возможности

- 🎭 Ветвящийся сюжет с переменными **близости** (`affection`) и **доверия** (`trust`), **3 финала**
- 🖼️ Полностью **векторный визуал** (инлайн-SVG): живые сцены (телефон, кафе, парк на закате,
  звёздное небо, спальня, рассвет) и **героиня Анна с мимикой** (улыбка, смущение, смех,
  нежность, удивление, грусть) + румянец
- ✨ Анимация: мерцающие звёзды, падающая звезда, боке, светлячки, дыхание персонажа
- 💬 Печатающийся текст, авто-режим, перемотка
- 💾 Сохранение/продолжение (localStorage)
- 🔞 **Переключатель контента**: режим 18+ (полные сцены) и «мягкий» режим (для маркетов)
- 📱 Адаптив под телефон + PWA-манифест (ставится «как приложение»)

## Как запустить (локально)

Из-за политики браузеров просто открыть `index.html` двойным кликом может не дать загрузить шрифты/манифест. Лучше поднять локальный сервер:

```bash
cd love-novella
python3 -m http.server 8000
# открой http://localhost:8000
```

Или любой другой статический сервер (`npx serve`, расширение Live Server в VS Code и т.п.).

## Как править/расширять сюжет

Весь текст и ветки — в `js/story.js`. Модель «пассажей»:

```js
my_scene: {
  bg: "park_night",    // фон из art.js: phone/cafe/park_eve/park_night/sky/home/bedroom/dawn/morning
  char: "anna",        // показать героиню; null — спрятать
  expr: "soft",        // мимика: neutral/smile/happy/soft/laugh/surprise/sad
  blush: true,         // румянец
  lines: [
    { who: "Анна", expr: "smile", text: "Реплика героини (можно менять expr/blush прямо в строке)." },
    { text: "Строка без who — это мысли Романа / повествование." },
    // строка 18+ с мягким вариантом:
    { text: "нейтральный текст",
      adult: "откровенный вариант (режим 18+)",
      soft:  "мягкий вариант (для маркета)" },
  ],
  then: {
    choices: [
      { label: "Вариант ответа", hint: "подсказка", set: { affection: 2, trust: 1 }, goto: "next_scene" },
    ],
  },
}
```

`then` бывает: `{ goto }`, `{ choices:[...] }`, `{ ending }`,
либо функция `(vars) => ({...})` для условных переходов по `affection`/`trust` (см. `climax_answer`).

**Визуал** правится в `js/art.js`: `SCENES` — словарь SVG-сцен, `CHARACTER` — SVG героини
с группами мимики (рты `m-*`, веки `lid-*`, румянец `blush`). Финалы — `ENDINGS` в конце `story.js`.

## 🔞 Про 18+ и Google Play — важно

Google Play **запрещает** откровенно сексуальный контент (Sexual Content and Profanity policy).
Поэтому стратегия — **одна кодовая база, две сборки**:

| Версия | Режим контента | Где публиковать |
|---|---|---|
| **Adult / Full** | 18+ включён | itch.io, прямой APK, свой сайт, веб |
| **Play-safe** | «мягкий» режим | Google Play |

Как зафиксировать режим для конкретной сборки: в `js/engine.js`, в объекте `cfg`,
поставь `adult: false` для Play-сборки (и можно убрать из настроек переключатель 18+).
Содержание сцен при этом не теряется — интим уходит в `soft`-вариант с затемнением.

Даже «мягкая» романтическая версия — это рейтинг **Teen/16+** в анкете IARC при публикации. Заполни анкету честно.

## 📦 Упаковка в Android-приложение (Capacitor)

Самый простой путь обернуть HTML5-игру в `.aab` для Google Play:

```bash
# 1. инициализация (в папке love-novella)
npm init -y
npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Тёплый дождь" "ru.warmrain.app" --web-dir=.

# 2. добавить андроид-платформу
npx cap add android

# 3. синхронизировать веб-файлы и открыть в Android Studio
npx cap sync
npx cap open android
```

Дальше в Android Studio: **Build → Generate Signed Bundle/APK → Android App Bundle (.aab)**.
`.aab` загружается в Google Play Console.

**Для оффлайн-сборки** замени CDN-шрифты Google Fonts на локальные файлы:
скачай `Cormorant Garamond` и `Manrope`, положи в `css/fonts/`, подключи через `@font-face`
и убери `<link>` на `fonts.googleapis.com` из `index.html`.
Иначе без интернета шрифты не загрузятся (логика игры при этом работает).
