# 🌲 Лесная гонка 3D

Простая 3D-гонка для **Яндекс Игр** на Three.js. Машина едет по бесконечной
лесной трассе, игрок маневрирует влево/вправо, собирает заправку и объезжает
препятствия. Закончилась заправка — игра окончена.

## Геймплей

- **Выбор машины:**
  - ⚡ **Электро** — собирает батареи 🔋, экономный расход, шустрая.
  - ⛽ **Бензин** — собирает канистры 🛢️, мощный разгон, прожорливый бак.
- Заправка (батарея/канистра) пополняет бак, препятствия (пни) бьют по запасу
  и сбрасывают скорость.
- **Бонусы-ускорители** 🚀 (золотые кристаллы) дают временный буст скорости.
- **Биомы** сменяются по дистанции: лес → закат → зима (со снегом).
- **Звук:** синтезированный гул двигателя + эффекты сбора/удара (кнопка 🔊 в HUD,
  без звуковых файлов — всё на WebAudio).
- Очки начисляются за дистанцию и собранную заправку. Рекорд хранится локально,
  а на платформе отправляется в таблицу лидеров Яндекса.

## Управление

- **Клавиатура:** ← → или `A` / `D` (и `Ф` / `В`).
- **Телефон:** экранные кнопки ◀ ▶ либо удержание пальца на левой/правой
  половине экрана.

## Локальный запуск

Нужен любой статический сервер (из-за ES-модулей `file://` не подойдёт):

```bash
cd forest-racing
python3 -m http.server 8080
# открыть http://localhost:8080
```

## Структура

```
forest-racing/
├── index.html              # разметка, HUD, меню, подключение SDK
├── style.css               # стили интерфейса
├── js/game.js              # вся игровая логика на Three.js
├── js/vendor/three.module.js  # Three.js r160 (локально, без CDN)
└── README.md
```

Three.js подключается локально через importmap, поэтому игра полностью
самодостаточна и не требует интернета для движка — можно сразу паковать в ZIP.

## Публикация в Яндекс Играх

1. В `index.html` уже подключены:
   - Yandex Games SDK: `https://yandex.ru/games/sdk/v2`
   - вызовы `LoadingAPI.ready()`, `GameplayAPI.start/stop()` и показ
     полноэкранной рекламы между забегами (`adv.showFullscreenAdv`).
2. Three.js уже лежит локально (`js/vendor/three.module.js`), игра не зависит
   от внешних CDN — это требование самодостаточности для Яндекс Игр выполнено.
3. Соберите ZIP из содержимого папки `forest-racing/` (важно: `index.html`
   должен быть в корне архива) и загрузите в консоли разработчика Яндекс Игр.

## Таблица лидеров

В `js/game.js` имя лидерборда задаётся константой `LEADERBOARD_NAME`
(`forest_score`). Создайте лидерборд с таким же техническим именем в консоли
разработчика Яндекс Игр. Локально и без SDK отправка очков просто пропускается.

## Идеи для развития

- Сохранение прогресса игрока через `player.setData`.
- Разные модели машин и апгрейды за очки.
- Дневной/ночной цикл, погода (дождь, туман).
