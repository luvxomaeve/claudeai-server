# Waifu Touch

Прототип браузерной игры: 3D аниме-девушка (VRM), которая реагирует на касания.
Работает на компьютере и телефоне, без сборки — three.js и three-vrm грузятся с CDN.

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать через локальный сервер, а не двойным кликом по `index.html` (ES-модули не работают с `file://`).
Для GitHub Pages ничего настраивать не нужно — это просто статика.

## Что умеет

| Касание | Реакция |
|---|---|
| Гладить по голове (зажать и водить) | улыбается, клонит голову, растёт симпатия, сердечки |
| Лицо | пугается, поднимает руки |
| Ладонь | машет / даёт пять |
| Плечо, рука | оборачивается, качается |
| Грудь, бёдра | злится (на высокой симпатии — смущается) |
| Живот, ноги | смеётся от щекотки, подпрыгивает |
| Тыкать слишком часто | обижается и отворачивается |
| Водить пальцем по лицу, рукам, телу, ногам | мягкая реакция: ёжится, смущённо сводит колени, краснеет |

Одежда и волосы с физикой качаются от касаний (толчок только вбок/назад).

Позы (кнопка «Поза» внизу): стоит, кокетка, руки в боки, скрестила руки, скромница, руки за спиной, задумалась, привет.
Кнопка ✏️ включает **позу пальцем**: тяни её за руку — рука идёт за пальцем, локоть сгибается сам (IK);
тяни за голову — поворачивает голову; за грудь — наклоняет корпус; за таз — сдвигает бёдра (вниз — приседает).
Ещё: за ступню — поднять/отставить ногу, за живот — повернуть корпус. Светящиеся точки показывают, за что тянуть.
**Ползунок слева** (в любом режиме): тяни вниз — присед → на колени → сидит боком → лежит; вверх — встаёт.
**Свайп по пустому месту:** вниз — присед → на колени → сидит боком на полу → ложится на бок на локоть; вверх — встать; вбок (в режиме позы/камеры) — повернуть камеру.
«Сохранить» превращает позу в кнопку «★» (хранится в браузере). Готовые позы — в `POSES` в `src/character.js`.

Ещё: в покое переминается с ноги на ногу, оглядывается, потягивается; моргание, дыхание, взгляд и голова следят за курсором/пальцем, рот двигается во время реплик,
озвучка через синтез речи браузера (🔊), шкала симпатии с тремя уровнями (сохраняется в браузере),
скучает, если её долго не трогать. Кнопка 🎯 показывает зоны касаний.

## Гардероб 👗

- **Наряды:** сделай в VRoid Studio одну и ту же девушку в разных нарядах, экспортируй каждый в `.vrm`
  и добавь через «+ Добавить наряд» (или перетащи файл в окно). Переодевается со вспышкой,
  поза, танец и симпатия сохраняются. Наряды хранятся в браузере (IndexedDB).
- **🖤 Готик-образ одной кнопкой:** чёрная одежда и волосы, чулки, тёмная атмосфера.
- **Чулки:** рисуются прямо на коже модели (чёрные, тонкие, бордо, белые) с кружевной полосой,
  снимаются/надеваются кнопкой. Работает с моделями VRoid (материал тела `*Body*SKIN*`).
- **Волосы:** перекраска (чёрные, слива, пепел, розовые, алые).
- **🎥 Режим камеры** (кнопка вверху): свайп — крутить вокруг неё. Справа тонкая колонка: ＋ − (зажми — непрерывно),
  ⛶ (во весь рост / крупно), ⌂ — вернуть вид. Она же есть в режиме позы (там камера сама встаёт во весь рост).
  **Щипок двумя пальцами (или колесо) — зум в любом режиме.** Своя поза удаляется крестиком × на её кнопке.
  В обычном режиме касания только вызывают реакции, камера стоит на месте.
- **Цвет одежды:** перекраска материалов одежды (у моделей VRoid в имени материала есть `CLOTH`):
  готика, бордо, фиалка, роза и т.д.

## Анимации 🎬

- **Ноги на полу:** ступни стоят на месте, колени сгибаются сами под движение бёдер (IK), в покое и в танце.
- **Живость:** постоянно переносит вес с ноги на ногу, покачивает бёдрами, иногда оглядывается,
  поправляет волосы, пружинит на носочках, потягивается.
- **Танец:** кнопка «💃 Танцевать».
- **База движений (mocap):** жесты из записей живых людей — реверанс, поклон, помахать, потянуться, пожать плечами.
  «✨ Живое ожидание» берёт из записей ожидания только сглаженное движение верха тела (ноги свои, стоят на полу). Данные: CMU Graphics Lab Motion Capture Database (mocap.cs.cmu.edu, свободны для любого
  использования; BVH-конвертация B. Hahne), сконвертированы `tools/cmu-convert.mjs` в `mocap/*.json`.
- **Встроенные анимации:** милое ожидание, кокетливо, застенчиво, радуется, милый танец.
- **Mixamo:** загрузи `.fbx` с mixamo.com (бесплатно, аккаунт Adobe; скачивать «FBX Binary», «Without Skin») —
  движения переносятся на её скелет, уход по сцене убирается.
- **Mocap:** загрузи готовую анимацию `.vrma` (например, бесплатные паки от pixiv на Booth) —
  она заменит позы. Одежда и волосы с физикой (spring bones) колышутся от любых движений.

## Своя модель

1. Сделай персонажа в [VRoid Studio](https://vroid.com/studio) (бесплатно) и экспортируй в `.vrm`.
2. Перетащи файл в окно игры или нажми 📂.
3. Чтобы модель грузилась по умолчанию — положи её, например, в `models/waifu.vrm`
   и поменяй `DEFAULT_MODEL` в `src/main.js`.

Сейчас по умолчанию грузится тестовая модель из репозитория three-vrm (pixiv) — это заглушка.

## Структура

- `src/main.js` — сцена, камера, загрузка модели, касания, реплики, симпатия, UI.
- `src/character.js` — анимация: поза, дыхание, моргание, эмоции, движения-реакции, зоны касаний.
- `src/dialogue.js` — все реплики и реакции по зонам и уровням симпатии. Править тексты — здесь.

## Идеи на потом

- Анимации из Mixamo (`.fbx` → VRM retarget) вместо процедурных поз.
- Нормальная озвучка (заранее записанные или TTS-фразы).
- Гардероб / фоны, открываемые симпатией.
- Чат с ИИ, чтобы эмоции и позы менялись под ответ.
